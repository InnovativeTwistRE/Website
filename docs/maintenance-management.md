# Maintenance Management PRD
Version: 1.0

## Purpose
Centralize maintenance requests from tenants, owners, and internal staff.

## Workflow
Request → Review → Assign Vendor → Schedule → Complete → Quality Review → Close

## Features
- Photo uploads
- Video uploads
- Priority levels
- Vendor assignment
- Status timeline
- Owner approval when required
- Cost tracking
- Before/after documentation

## Notifications
Automatic updates for tenants, owners, vendors, and managers.

## AI
Categorize requests, summarize issues, detect recurring problems, and recommend preventive maintenance.

## Acceptance Criteria
Every request has a complete audit trail and document history.

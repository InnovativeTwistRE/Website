# Canonical Reference
Version: 1.0

## Purpose
This document is the single source of truth for shared platform terminology and enumerated values. All future specifications must reference this file and must not redefine these concepts independently.

## Governance Rule
When a new file genuinely requires a new role, account status, lead type, inspection type, or report name, place the following notice at the very top of the file:

`New [role/type/status/report] introduced: X — needs review`

Do not silently introduce new canonical values.

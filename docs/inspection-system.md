# Inspection System PRD
Version: 1.0

## Purpose
Digitize move-in, periodic, renewal, and move-out inspections.

## Inspection Types
- Move-In
- Quarterly
- Semi-Annual
- Annual
- Renewal
- Move-Out

## Required Features
- Mobile friendly
- Room-by-room checklist
- Photos
- Video
- Signatures
- Notes
- Deficiency tracking
- PDF generation
- Version history

## AI
Generate inspection summaries and compare previous inspections.

## Acceptance Criteria
Inspection reports integrate with tenant, owner, property, and document records.

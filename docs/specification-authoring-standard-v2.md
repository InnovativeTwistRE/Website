# Specification Authoring Standard
Version: 2.0

## Purpose
Define the required structure for every future specification.

## Canonical References
Every specification must be checkable against canonical-reference.md.

## Required Opening Sections
1. Dependencies
2. Canonical References
3. Purpose

## Required Document Sections
- Dependencies
- Canonical References
- Purpose
- Related Specifications
- Functional Requirements
- Data Model
- Permissions
- Automation
- AI Behavior
- Analytics
- Acceptance Criteria
- Revision History

## New Canonical Value Rule
When introducing a value not found in canonical-reference.md, place this line at the top:

`New [role/type/status/report] introduced: X — needs review`

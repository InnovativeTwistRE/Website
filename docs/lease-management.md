# Lease Management PRD
Version: 1.0

## Purpose
Manage the full lease lifecycle.

## Lifecycle
Application → Approval → Draft Lease → Signatures → Active Lease → Renewal → Move-Out

## Features
- Lease templates
- E-signatures
- Renewal tracking
- Rent changes
- Addenda
- Pet management
- Document archive

## AI
Summarize lease terms, identify renewal opportunities, and detect missing documents.

## Acceptance Criteria
Every lease version is retained with full audit history.

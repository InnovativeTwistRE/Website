
# Website Standards PRD
Version: 1.0

## Purpose
This document defines global rules for every public page on the Innovative Twist Real Estate website.

## Design Goals
- Education before sales
- Premium, minimal interface
- Fast performance
- Consistent navigation
- Accessible to all users

## Global Header
Components:
- Logo
- Primary navigation
- Search
- Client Login
- Schedule Consultation CTA

Header remains sticky after scrolling.

## Footer
Sections:
- Company Information
- Quick Links
- Resources
- Social Media
- Contact Information
- Legal
- Newsletter Signup

## Global Components
- Hero Banner
- CTA Banner
- Testimonial Carousel
- FAQ Accordion
- Resource Cards
- Property Cards
- Team Cards
- Statistic Cards

## Performance
- Largest Contentful Paint under 2.5s
- Lazy-load images
- Modern image formats
- Code splitting

## Accessibility
- WCAG AA
- Keyboard navigation
- Visible focus states
- Semantic HTML
- Screen reader labels

## Analytics
Track:
- Page views
- Scroll depth
- CTA clicks
- Form submissions
- Downloads
- Video plays

## CMS
All marketing copy, testimonials, FAQs, team members, and featured resources must be editable without code changes.

## Acceptance Criteria
Every page must inherit these standards before release.

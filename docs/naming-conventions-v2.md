# Naming Conventions
Version: 2.0

## Canonical References
All shared terminology must match canonical-reference.md exactly.

## Standards
- Use kebab-case for Markdown filenames.
- Use singular entity names.
- Use exact canonical capitalization for User Roles.
- Use exact lowercase underscore values for Account Status Values, Lead Types, and Inspection Types.
- Use exact canonical display names for reports.
- Do not create aliases unless documented in canonical-reference.md.

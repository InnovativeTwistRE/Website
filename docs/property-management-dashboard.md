# Property Wealth Management™ Dashboard PRD
Version: 1.0

## Purpose
Operational dashboard for managing rental portfolios, owners, tenants, leases, inspections, maintenance, accounting integrations, and communications.

## Dashboard Sections
- Portfolio Overview
- Occupancy
- Lease Expirations
- Maintenance Queue
- Rent Collection Status
- Owner Messages
- Tenant Messages
- Inspection Calendar
- Financial Snapshot
- AI Insights

## Core Modules
- Properties
- Owners
- Tenants
- Leases
- Work Orders
- Vendors
- Inspections
- Documents
- Reporting
- Communications

## Workflows
Lead → Owner Onboarding → Property Setup → Marketing → Screening → Lease → Active Management → Renewal/Move-Out

## AI
- Lease renewal recommendations
- Maintenance prioritization
- Risk detection
- Monthly owner summaries

## Acceptance Criteria
All activities are permission-controlled, audited, and integrated with Reporting Engine, File Storage, CRM, and Propertyware.

# Calculator Framework PRD
Version: 1.0

## Purpose
Provide a unified framework for every financial, real estate, and investment calculator across the platform.

## Design Principles
- Consistent user experience
- Explain every result
- Save calculations
- Generate reports
- AI-assisted interpretation

## Initial Calculators
- Mortgage
- Affordability
- Rent vs Buy
- Equity
- Seller Net Sheet
- Cash Flow
- NOI
- Cap Rate
- ROI
- BRRRR
- Flip
- WealthScore™

## Common Features
- Responsive forms
- Scenario comparison
- Shareable results
- PDF export
- CRM integration
- Report generation

## AI
Explain results in plain language and recommend next educational resources.

## Acceptance Criteria
All calculators use shared components, validation rules, and Reporting Engine output.
